# דשבורד מתכנן — V4

מתכנן יומי · שבועי · חודשי · שנתי, בעברית מלאה, עם לוח עברי, זמני היום,
ניהול סטודיו צילום, ועבודה מלאה גם בלי אינטרנט.

**קובץ אחד. בלי התקנה, בלי build, בלי תלויות חיצוניות.**

---

## התחלה מהירה

לחיצה כפולה על `index.html`. זהו.

בפינה הימנית העליונה צריך להיות כתוב **V4.0**. אם כתוב משהו אחר — `Ctrl+Shift+R`.

---

## מנהג

היישום מוגדר כברירת מחדל למנהג **עדות המזרח**:

* צאת שבת — 30 דק׳ אחרי השקיעה (ניתן לשנות ל-20 לפי הרב עובדיה יוסף זצ״ל)
* הדלקת נרות — 20 דק׳ לפני השקיעה
* סוף זמן ק״ש ותפילה — חישוב הגר״א
* ספירת העומר — ימי אבלות עד ל״ג בעומר, היתר מבוקר ל״ד
* בין המצרים — חתונות מותרות עד ר״ח אב; תשעת הימים מחמירים
* סליחות — מר״ח אלול
* אזכרה באדר בשנה מעוברת — באדר ב׳

ניתן להחליף למנהג אשכנז ב**הגדרות ← מיקום וזמני היום ← מנהג**.

> ההצגה היא של מנהג, לא פסיקה. בשאלה למעשה — לרב שלך.

**בדיקת זמנים:** הגדרות ← מיקום וזמני היום ← "בדיקת זמני שבת" מציג שש שבתות
קדימה עם השקיעה האמיתית, כדי להשוות ללוח שלך.

## מה יש

**לוח** — יום, שבוע, חודש, שנה, אג׳נדה ומשימות. לוח עברי ולועזי, מעבר ביניהם
או שילוב. חגים, פרשת שבוע, זמני היום, ספירת העומר, דף יומי, מזג אוויר.

**סטודיו** — עבודות עם סטטוס, כספים, דוח שעות, אנשי קשר, הצעות מחיר, חוזים,
חשבוניות וקבלות עם מספור רץ, מחירון, צוות, צנרת פניות, תזרים 12 חודשים,
רווחיות לעבודה, עומס עונתי, מעקב מסירה.

**תכנון** — משימות עם תת-משימות, קטגוריות, הערכות זמן ותלויות; משימות קבועות,
תבניות יום ושבוע, לוח קנבן, תכנון אוטומטי של היום, צ׳קליסטים, פומודורו, מצב פוקוס.

**קלט מהיר** — `Ctrl+N` ומשפט בעברית: "מחר ב-4 צילום משפחה באשקלון".

## קיצורים שכדאי לזכור

| מקש | מה |
|---|---|
| `Ctrl + N` | הוספה מהירה בעברית |
| `Ctrl + K` | חיפוש · `Ctrl + P` לוח פקודות |
| `Ctrl + Z` | ביטול פעולה |
| `E` | **מצב עריכת פריסה** — גרירת בלוקים על הלוח |
| `W` | מצב קיר הסטודיו · `D` תצוגה מפוצלת |
| `1`–`6` | מעבר בין התצוגות · `T` היום |
| `?` | כל הקיצורים |

## סידור הלוח לפי הטעם שלך

לחיצה על ✋ בסרגל (או `E`) מפעילה **מצב עריכת פריסה**:

* גוררים בלוק לכל מקום — בתוך עמודה או בין עמודות
* `‹` `›` מזיזים עמודה בלי גרירה
* `✕` מסתיר בלוק
* `↺ החזרת הכול` מחזיר מוסתרים · `איפוס סדר` חוזר לברירת המחדל

הסידור נשמר מיד, ונפרד לכל תצוגה (יום, שבוע, חודש, שנה).

---

## גיבוי

**הגדרות ← נתונים וגיבוי ← ייצוא גיבוי JSON**, או `Ctrl+S`.

היישום מזכיר לבד אחת לשבוע. בגרסת המחשב הגיבוי נשמר לבד, פעם ביום,
לתיקיית `backups` שליד קובץ הנתונים.

**אם משהו השתבש:** הוספת `?rescue=1` לכתובת פותחת מסך חילוץ ושחזור.
`?reset=1` מתחיל נקי (עם אפשרות להוריד גיבוי קודם).

## גרסת המחשב

`V4-Desktop` — אפליקציה עצמאית להתקנה, שמאחסנת הכול בקבצים על המחשב.

```bash
npm install
npm run dist
```

הקוד נבנה אוטומטית מקובץ הווב (`build-renderer.js`), כדי שלא תהיה כפילות.
**אין לערוך ידנית את `renderer/index.html`** — הוא נדרס בכל בנייה.

הנתונים עוברים כמו שהם. כדאי לייצא גיבוי JSON לפני, ואחרי הפתיחה לעשות
